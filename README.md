# Livedoor 空冷VWブログ

このリポジトリは、空冷ビートル／空冷VWの記事を日本語で生成し、Livedoor Blogへ公開する処理を管理します。空冷VW記事の主掲載先は独自ドメイン kazuhiro-beetle.com です。

## 記事作成の基本方針

- 1記事につき読者の具体的な疑問を一つ扱い、冒頭で要点を伝える。
- タイトルと要約には「空冷ビートル」「空冷VW」などの中心語句を自然に含める。キーワードを詰め込まない。
- 年式・価格・整備費・故障原因・地名・店舗名など、根拠や入力にない情報を作らない。
- 筆者本人の所有・運転・修理経験を、確認なしに体験談として書かない。
- 既存記事の本文が同一なら公開をスキップし、内容が異なる場合はタイトル衝突だけを理由に捨てない。
- はてななど他ブログに同じ本文をそのまま転載しない。

## ファイル

- generate-post.js — 日本語記事の生成
- post.yml — 生成記事データ（実行時に作成）
- steemit-to-livedoor.js — Livedoor AtomPubへの投稿と重複確認
- livedoor-dedupe.js — 記事履歴との重複判定

## 公開前の確認

自動生成されたタイトル・要約・本文・画像を確認し、事実と推測が混ざっていないか確認してください。GitHub Actionsのワークフロー定義や実行スケジュールは変更していません。

## 必要なGitHub Actions Secrets

- OPENAI_API_KEY — 記事生成
- LD_USER — LivedoorのユーザーID
- LD_API_KEY または LD_PASSWORD — AtomPub認証

認証情報を記事、ログ、READMEに記載しないでください。
